\# ⚽ Quanto é em Campos?



Uma ferramenta gratuita para comparar áreas e dimensões com campos de futebol.



\## 🌐 Acesse



\[Quanto é em Campos](https://jacksoncosta08.github.io/quanto-em-campos/)



\## 📏 O que a ferramenta faz?



\- Conversão de áreas para campos de futebol

\- Suporte a m²

\- Hectares

\- Acres

\- Cálculo através das dimensões de um terreno

\- Comparação visual proporcional

\- Zoom na área de visualização

\- Movimentação da área demarcada



\## 🛠️ Tecnologias



\- HTML5

\- CSS3

\- JavaScript

\- SVG
